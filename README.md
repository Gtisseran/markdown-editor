# Markdown Editor

A minimalist, real-time Markdown editor and viewer built with vanilla JavaScript and auto-saved in `localStorage`.

## Features
- Real-time Markdown rendering using Marked.js
- Automatic persistent storage via `localStorage`
- Responsive layout (side-by-side view on desktop, stacked on mobile)
- Clean and lightweight interface

## Tech Stack
- HTML5 / CSS3
- JavaScript (Vanilla)
- [Marked.js](https://marked.js.org/)
